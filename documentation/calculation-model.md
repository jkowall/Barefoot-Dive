# Calculation model

## Implemented model

The pure engine uses 16-compartment ZH-L16C inert-gas kinetics for nitrogen and helium, with coefficient metadata identifying the DecoTengu/OSTC-derived set (`decotengu-0.14.1-coefficients-v1`). It tracks tissue state through explicit exposure events, computes GF-adjusted ceilings, rounds stops to the configured grid, and schedules deterministic ascent/stops. Inputs and outputs use branded metres, seconds, bar absolute, litres, and fractions.

Breathing events support OC bottom/travel/deco gases, constant-setpoint CCR diluent/setpoint exposure, CCR setpoint activation/deactivation, and bailout. The CCR bailout plan starts from the exact tissue/depth/runtime state at `bailoutTriggerSecondsAtDepth`. Gas accounting integrates ambient pressure over each segment and applies fixed, custom, thirds, sixths, or rock-bottom reserves, reporting insufficiency and reserve-crossing diagnostics.

The cave module supplies explicit penetration and exit events and scenario transformations to the same production event engine. Each route segment resolves a physically accessible, depth-eligible gas/cylinder; stage drops and recovery determine later accessibility. Gas-derived maximum time/distance uses a bounded search over proportionally scaled copies of the entered route. Every candidate is rerun through the tissue engine, ascent/decompression scheduler, and every actually used cylinder ledger; CCR candidates use the exact end-of-penetration bailout plan. A numeric maximum is emitted only after a safe lower bound and unsafe upper bound are both established. Otherwise the result carries `GAS_LIMIT_UNDETERMINED` and omits the number. The reported turn pressure and minimum-required pressure identify the same actual cylinder, while the result separately identifies the cylinder with the limiting reserve margin.

Thirds and sixths expose their operational turn thresholds separately from the minimum pressure required at the planned turn. The CCR cave-level ledger is the bailout contingency ledger; normal CCR oxygen metabolism and diluent/loop consumables remain explicitly unmodeled. The module does not invent a ceiling-safe overhead route. A cave route must explicitly model the route and be checked; cave behavior is experimental pending qualified cave-diver review.

## Presets and limitations

`barefoot-zhl16c-v1`, `multideco-zhlc-compatible-v1`, and `shearwater-petrel3-v103-compatible-v1` are scheduling/settings presets with explicit experimental status. Their labels do not claim MultiDeco, Shearwater, firmware, or schedule parity. The implementation does not include repetitive dives, OTU, IBCD validation, or arbitrary profile authoring as validated capabilities.

The 11 calculator functions are production code paths, but their existence and unit tests do not establish operational safety. CNS uses the documented NOAA single-exposure table only from PPO2 0.6 through 1.6 bar. Barefoot Dive linearly interpolates between the listed rows as an explicit versioned implementation policy; NOAA is not cited as defining that interpolation. Values outside the table are rejected instead of extrapolated. CCR oxygen metabolism and diluent/loop consumables are not inferred from OC RMV in the normal CCR ledger.

The Tools redesign adds interaction policy around these functions, not a new decompression model. Best Mix and END use versioned PPO2/narcotic-policy identifiers and require the actual oxygen and helium fractions. With oxygen and nitrogen treated as narcotic, `END = ((Pambient × (1 − FHe)) − Psurface) × metersPerBar`; with nitrogen alone narcotic, `END = ((Pambient × FN2 ÷ 0.79) − Psurface) × metersPerBar`. Best Mix solves those equations in reverse while respecting the PPO2 ceiling and returns the complete active-constraint set.

SAC / RMV accepts either direct measured surface-gas volume or cylinder water volume plus a gauge-pressure drop, preserving the selected mode and source values. A moving-depth sample uses the arithmetic mean of start/end absolute pressure and therefore assumes depth changes linearly with time. Emergency Gas (Rock Bottom / Minimum Gas and Simplified Bailout) evaluates only an explicitly entered schedule through the same gas-integration primitive used by planner ledgers. OC requires an explicit team size and can return schedule gas without a cylinder or add one-cylinder pressure/sufficiency output; CCR requires one bailout cylinder. Every cylinder check requires an explicit reserve, including an intentional zero. It does not generate a decompression schedule or a CCR bailout plan; CCR bailout continues to use the exact-trigger planner path. Ambient pressure is absolute, cylinder pressure is gauge, and gas-use calculations consume gauge-pressure deltas.
